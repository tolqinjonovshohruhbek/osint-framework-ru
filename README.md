# OSINT Framework [RU] 🌐

Русскоязычная версия популярного интерактивного инструмента **OSINT Framework**. Это карта ресурсов для разведки на основе открытых источников (Open Source Intelligence), полностью адаптированная и переведенная для удобства пользователей.

## ✨ Особенности этой версии
- **Полная локализация**: Категории и описания инструментов переведены на русский язык.
- **Современный UI**: Темная тема, адаптивный дизайн и плавная анимация.
- **Удобный поиск**: Мгновенный поиск по названиям и описаниям инструментов (Ctrl+K).
- **Живая статистика**: Подсчет инструментов в каждой категории в реальном времени.
- **Интерактивная легенда**: Четкое разделение инструментов по типам (T — локальные, D — дорки, R — регистрация, M — ручной ввод).

## 🚀 Как пользоваться
Просто выберите нужную категорию в меню слева. Если вы ищете что-то конкретное, воспользуйтесь поисковой строкой сверху.
